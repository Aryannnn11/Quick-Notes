# 📝 Quick Notes

Quick Notes is a lightweight and responsive note-taking web application built using **HTML, CSS, and JavaScript**. It allows users to create, edit, delete, search, and pin notes while storing data locally in the browser.

## ✨ Features

* 📝 Create, edit, and delete notes
* 🔍 Real-time search by note title or content
* 📌 Pin important notes to the top
* 💾 Persistent storage using LocalStorage
* 🌙 Dark and light theme support
* 🕒 Created/updated timestamps
* 🔢 Character counter while writing notes
* 📱 Responsive design for desktop and mobile
* 🔒 HTML escaping for safer note rendering

## 🛠️ Tech Stack

* **HTML5** — Application structure
* **CSS3** — Responsive UI, animations, and theme styling
* **JavaScript (ES6)** — Application logic and DOM manipulation
* **Web Storage API** — Persistent browser-based note storage

## 🚀 Getting Started

Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

Open the project folder:

```bash
cd quick-notes
```

Then open `index.html` in your browser.

No additional packages or dependencies are required.

## 💡 How It Works

Notes are stored inside the browser using the **LocalStorage API**. JavaScript handles CRUD operations, searching, pinning, theme persistence, timestamps, and dynamic rendering of notes without requiring a backend or database.
